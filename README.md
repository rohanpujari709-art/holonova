**HoloNova – A Next-Generation Portable Screen-Free 3D Holographic Display System**

HoloNova is an innovative, portable holographic display system that uses rotating LED blades to create a floating 3D visual experience without physical screens or special glasses. The system uses ESP32-S3 and LED technology to display attractive and interactive 3D content.

It aims to make visualization more realistic, engaging, and accessible for applications in education, advertising, entertainment, and exhibitions.

**Key Features:**
- Screen-free 3D visualization.
- Portable and compact design.
- Rotating LED-based display technology.
- Interactive and engaging visual experience.
- Applications in multiple industries.
